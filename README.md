# Corsara-
the public GitHub repository URL of README.md file, which contains the details about a simple interest calculator.
Aim
To develop a program that calculates simple interest using the principal amount, rate of interest, and time period.

Formula
The formula for calculating simple interest is:

Simple Interest = (Principal × Rate × Time) / 100

Where:

Principal (P): The initial amount of money invested or borrowed.
Rate (R): The annual rate of interest in percentage.
Time (T): The duration for which the money is invested or borrowed, measured in years.
The total amount is calculated as:

Total Amount = Principal + Simple Interest

Features
Accepts the principal amount from the user.
Accepts the annual interest rate.
Accepts the time period in years.
Calculates simple interest using the standard formula.
Displays the simple interest and total amount.
Easy to use and beginner-friendly.
Technologies Used
Programming Language: Python
Platform: Any system with Python installed
Editor: VS Code, IDLE, or any text editor
